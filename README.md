# map-locations-cw3

> Интерактивная карта горных локаций с поиском маршрутов и определением позиции по переходам.


Этот проект помогает ориентироваться на карте гор Озерной Вселенной. Отмечайте переходы на сетке 6×10 — система автоматически определит вашу текущую локацию. Доступен поиск кратчайшего пути между локациями.

## Использование

1. **Определение локации**  
   Отметьте переходы → нажмите `ОПРЕДЕЛИТЬ`.
2. **Поиск маршрута**  
   Выберите 2 локации → нажмите `КРАТЧАЙШИЙ ПУТЬ`.
3. **Визуализация**  
   Все переходы показаны в нижней части страницы.
